# Persona catalog

Each role definition is behavioral metadata. Runtime write grants are resolved by the ownership kernel and can never be declared here. Production-read-only roles are architect, UI/UX designer, security auditor, accessibility auditor, code reviewer, evidence agent, and release agent (except task-scoped artifacts or Git/PR metadata explicitly provided by later adapters).

Implementation roles are frontend, backend, mobile, and database. QA owns acceptance/E2E test assets. Integration is limited to mechanical combination. Director and Coordinator orchestrate but do not acquire specialist production paths.
